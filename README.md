# Волна

Музыкальный каталог с точными ID исполнителей Deezer, поиском, страницами артистов, локальными плейлистами и стандартным встроенным плеером YouTube.

## Запуск

Python 3.12: `pip install -r requirements.txt`, затем `python server.py`.
По умолчанию приложение слушает порт 4175; Render задаёт `PORT`.
Docker: сборка из Dockerfile в корне репозитория, стартовая команда уже задана.

## Конфигурация

- `ALLOWED_ORIGINS`: разрешённые внешние источники через запятую. Для фронтенда Sites указан его текущий домен.
- `YOUTUBE_API_KEY`: необязательный серверный ключ YouTube Data API v3. Предпочтителен для облачного поиска; задавать только через секреты Render, не добавлять в Git.
- Без ключа поиск идентификатора видео использует метаданные yt-dlp. Доступность зависит от ограничений YouTube для IP сервера.
- `public/config.js`: пустой `VOLNA_API_BASE` использует тот же домен. Для отдельного фронтенда Sites установить HTTPS-адрес API-сервера.

## Источники

Deezer предоставляет только сведения о релизах и исполнителях. Название и канал фактически воспроизводимого видео показывает стандартный плеер YouTube. Совпадение находится поиском; его точность не гарантируется. Видео может быть недоступно по стране, аккаунту, настройкам встраивания или решению правообладателя. Реклама YouTube сохраняется. Эта программа не предоставляет лицензию на музыку, не обещает все песни и не извлекает или проксирует аудио YouTube.

Сохранения браузера v4 отделены от старых данных Audius. Свои файлы не загружаются на сервер.

## API

- `GET /health`
- `GET /api/v1/tracks/search?query=Баста&limit=50&offset=0`
- `GET /api/v1/users/search?query=Баста`
- `GET /api/v1/users/dz-4170146`
- `GET /api/v1/users/dz-4170146/tracks?limit=50&offset=0`
- `GET /api/v1/tracks/dz-2248173007/stream`: JSON с идентификатором видео для стандартного YouTube embed; не аудиофайл.

На бесплатном Render сервер может засыпать при отсутствии запросов. Первый запрос после сна потребует дополнительного времени.
